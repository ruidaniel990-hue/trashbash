# Icons

SVG emoji from [Twemoji](https://github.com/jdecked/twemoji) (npm `@twemoji/svg@15.0.0`).
Graphics licensed under CC-BY 4.0 (https://creativecommons.org/licenses/by/4.0/),
Copyright Twitter, Inc and other contributors. `LICENSE` is the npm package's own MIT license.

Only the emoji used by the game are bundled. `js/ui/icon-manifest.js` lists them;
any emoji not listed there falls back to the device's native emoji.
